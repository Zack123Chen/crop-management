# 🌾 Crop Management System (农作物管理系统)

这是我的第一个 Spring Boot 全栈练习项目，旨在打通从 Controller 到数据库的全链路查询。

## 🚀 核心功能
* **全链路查询**：实现了从前端请求到数据库响应的完整闭环。
* **数据模拟**：内置了农作物生长状态的模拟测试数据。

## 🛠️ 技术栈
* **后端**: Java, Spring Boot, MyBatis
* **工具**: Maven, Git, GitHub
